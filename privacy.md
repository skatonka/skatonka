# Privacy Policy

This OAuth application is used solely for my personal Google Drive backup and synchronization.

## Google Drive Access

The application uses Google OAuth to allow rclone, running on my personal Ubuntu computer, to access files in my own Google Drive account.

Google Drive data is used only to copy and synchronize my files between Google Drive and my personal computer.

## Data Storage

Files downloaded from Google Drive are stored on my personal computer.

OAuth credentials and authorization tokens used by rclone are stored locally on my personal computer.

## Data Sharing

Google user data accessed through this application is not sold, shared, or provided to third parties.

## Purpose

This application is for personal use only and is not offered to other users as a service.
